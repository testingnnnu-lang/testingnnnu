Step-by-Step Deployment & Setup Guide

Complete beginner guide to running, hosting, and connecting Supabase cloud backend for free.

Stage 1: Software & Prerequisites Preparation

1. Install VS Code: Download Visual Studio Code from code.visualstudio.com.

2. Free Accounts Needed: Register free accounts at github.com and supabase.com.

3. Local Runner: Install the VS Code extension "Live Server" to launch this HTML application locally with one click.

Stage 2: Code Structure & Single-File Architecture

This web application consolidates HTML markup, Tailwind CSS styling, FontAwesome vector iconography, Web Audio API sound synthesis, local storage state managers, and REST API sync triggers into a single optimized web file (index.html).

Stage 3: GitHub Hosting Integration
  1. Create a new public repository on GitHub named cpp-master-app.
  2. Upload this index.html file to the root of your repository.
  3. Navigate to Settings > Pages in your GitHub repository.
  4. Under Build and Deployment, select Source as Deploy from a branch and choose main / root.
  5. Click Save. GitHub Pages will issue a free URL (e.g. https://yourname.github.io/cpp-master-app).
Stage 4: Supabase Database Cloud Sync

1. Log into your Supabase Dashboard and click New Project.

2. Go to the SQL Editor tab inside Supabase, paste the DDL script found in the "Supabase SQL Schema" tab of this app, and click Run.

3. Go to Project Settings > API to copy your Project URL and anon key.

4. Click the "Local Only / Cloud Sync" button in the top navigation bar of this site and paste your credentials to enable cloud persistence.

Supabase SQL Setup DDL

Copy and execute this SQL script in your Supabase SQL Editor to establish backend tables and RLS security policies.

-- 1. Create User Learning Profiles Table
CREATE TABLE IF NOT EXISTS public.user_profiles (
    user_id UUID PRIMARY KEY DEFAULT auth.uid(),
    user_name TEXT DEFAULT 'Learner',
    current_level INT DEFAULT 1,
    xp INT DEFAULT 0,
    streak INT DEFAULT 1,
    total_time_mins INT DEFAULT 0,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Create Lesson Completion Logs Table
CREATE TABLE IF NOT EXISTS public.lesson_progress (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES public.user_profiles(user_id) ON DELETE CASCADE,
    level_id INT NOT NULL,
    score INT NOT NULL,
    completed_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(user_id, level_id)
);

-- 3. Enable Row Level Security (RLS)
ALTER TABLE public.user_profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.lesson_progress ENABLE ROW LEVEL SECURITY;

-- 4. RLS Security Policies
CREATE POLICY "Allow individual read own profile" ON public.user_profiles
    FOR SELECT USING (auth.uid() = user_id);

CREATE POLICY "Allow individual write own profile" ON public.user_profiles
    FOR ALL USING (auth.uid() = user_id);

CREATE POLICY "Allow individual read own progress" ON public.lesson_progress
    FOR SELECT USING (auth.uid() = user_id);

CREATE POLICY "Allow individual write own progress" ON public.lesson_progress
    FOR ALL USING (auth.uid() = user_id);
